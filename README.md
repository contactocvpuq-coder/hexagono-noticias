# Noticias de Hexágono Ingeniería

`noticias.json` contiene las noticias aprobadas que muestra la página **Noticias** de la web de Hexágono Ingeniería.
La página lee este archivo directamente, así que al actualizarlo la web cambia en pocos minutos, sin subir nada por FTP.

Cada noticia tiene: `titulo`, `resumen`, `fecha` (AAAA-MM-DD), `categoria` (energias, industria, digital, innovacion), `fuente`, `url` y `traducida` (true/false).
